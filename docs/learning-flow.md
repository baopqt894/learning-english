# English Discovery Day: learning through a shared goal

The player is a new cadet helping Minh prepare a reading corner and picnic for English Discovery Day. The setting, characters and Vietnamese uniform identity remain intact. The interface supports A1–A2 practice; these are design targets, not a proficiency assessment.

| Chapter | Story action | Language the player practises |
| --- | --- | --- |
| A new teammate | Meet Minh and volunteer to help | Introductions, questions, offering help |
| Find the first clue | Find Ms. Lan at the library | Asking for directions, repeating details, greeting |
| A story worth sharing | Borrow an adventure story | Polite requests, borrowing periods, return dates |
| A change of plan | Find an alternative when a book is unavailable | Asking about options, choosing, confirming |
| The team picnic | Buy food within 30,000 dong | Asking prices, ordering, checking totals |
| Ready for discovery day | Organise supplies and report back to Minh | Transfer of previous skills across three locations |

## Play and learning loop

1. Read a short mission situation, communication goal and useful phrase. Optional English–Vietnamese vocabulary explains key words.
2. Travel to the highlighted NPC. The map marks the next task location; world exploration remains available.
3. Hear a context-specific NPC prompt. The conversation shows the current communication objective and progress.
4. Optional **Listen to a model** exposes a sample for rehearsal. It does not send an answer or grant progress.
5. Answer through **Speak** or **Type**. Speech recognition is always reviewed before submission. **Hint** is optional; guided mode opens extra support after two unsuccessful attempts.
6. Receive an in-character reply plus explicit learning feedback. Asking for repetition or explanation never grants progress. Successful communication advances to the next objective; a new place requires travelling there.
7. Complete a short comprehension/retrieval question. A wrong answer can be retried without losing progress. XP is awarded once, after the correct review answer.
8. Continue the shared story. The final chapter returns to Minh to explain what has been prepared.

## Portraits and environment

Each NPC has four generated static expressions in an atlas, derived from the original character portrait. Replies alternate appropriate expressions. Face geometry is never stretched, warped or animated. The atlas preserves a square aspect ratio. Voice playback is independent of the portrait.

Outdoor figures retain articulated 3D geometry and olive cadet uniforms, with larger readable silhouettes, cloth detail and softer shadows. The campus has fuller foliage, book displays and event signage. Map geometry still uses the navigation coordinates and highlights the next NPC; scenery additions avoid creating new route blockers.

## Current limitations

Dialogue uses authored prompts and intent patterns, not a generative language model. It accepts several common phrasings but cannot reliably judge arbitrary English, grammar or pronunciation. Review answers are not persisted separately; they gate reward collection in the current UI. Existing saves and previously earned XP are preserved, so returning players may start partway through the new story. A new run is available from the teacher screen.
